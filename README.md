# Nikhil Krishnan — Interactive Portfolio

**Geospatial Specialist & Technical AI Evaluator**  
Bruno Simon–inspired 3D driving experience · free on GitHub Pages.

## Live site

https://nikhilkrishnan-ai.github.io/nikhil-krishnan-portfolio/

## Experience

- **Drive** a 3D world (WASD / arrows) — like immersive portfolio sites
- **Stop at landmarks** and press **E** to open executive briefings
- **6 zones:** Profile · Credentials · Expertise · Track Record · GeoSense · Contact
- Mobile **browse mode** with touch controls
